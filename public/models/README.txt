The GLB was supplied by the website owner. The original GLB is kept unchanged.
Runtime modifications: geometry transforms are baked and the model is centered,
oriented and scaled for the web scene. The display material/UVs are adapted to
show the portfolio's project screenshots. Body finishes are adapted to approximate
Silver, Cosmic Orange and Deep Blue; mobile omits the extra screen-glass overlay.

The rendered scene includes linked creator, source and license attribution.
The original supplied license text is in iphone-17-pro-max-LICENSE.txt.

Web derivative: iphone-17-pro-max-web.glb (235,024 bytes, 17,157 triangles).
Original: 1,713,400 bytes, 29,544 triangles. The web derivative removes the unused
wallpaper, simplifies geometry with a 0.001 error bound, and uses Meshopt
compression/quantization. Rebuild with `node scripts/optimize-phone.mjs`.
Mobile runtime uses simpler body materials, smaller screen textures and lighting.
Creator attribution and CC BY 4.0 licensing apply to the derivative too.

Mobile orbit derivative: iphone-17-pro-max-orbit.glb (315,504 bytes,
29,544 triangles). This version preserves ALL original geometry, with 16-bit
position / 14-bit normal and UV quantization plus Meshopt compression and the
same wallpaper removal. Six instances share the geometry and camera textures.
Both derivatives rebuild with the script above.
